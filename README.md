# Career Orientation Platform

A full-stack web application designed to help students map their career path based on personal interests and skills.

## Project Progress Timeline

### 📅 Week 1: Infrastructure & Database Architecture
- Set up the core project layout for Django and React.
- Configured the SQLite database and initialized migrations.
- Created the structural schema for the core assessment and question application.

### 📅 Week 2: User Authentication & Profile Logic
- Implemented secure student registration and login endpoints.
- Integrated Simple JWT for continuous secure token authorization.
- Adapted the user Profile logic to store student education background, strengths, and career goals.
- Designed dynamic loading animations and transition visual effects in the React frontend.
